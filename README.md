# CodeAlpha Login & Registration System

A C++ based Login and Registration System developed as part of the CodeAlpha C++ Programming Internship — Task 2.

## 📌 Project Overview

This is a console-based authentication system developed in C++. It allows users to create an account and securely log in using their registered username and password.

The system stores registered user credentials in a local text file and validates login information before granting access.

## ✨ Features

- 👤 User Registration
- 🔐 User Login
- 📝 Username and Password Input
- 🚫 Duplicate Username Detection
- 💾 User Credentials Storage
- ✅ Login Validation
- ❌ Invalid Username/Password Handling
- 📂 Automatic User File Creation
- 📋 Simple Menu-Based Interface
- 🚪 Exit Option

## 🛠️ Technologies Used

- C++
- File Handling
- Functions
- Loops
- Conditional Statements
- Strings
- Input Validation
